## ของที่มีจริงในชุด

- เมือง P0 ฉากหลักต่อเนื่อง กว้าง 4,344 px, ชั้น sky/cloud/mountain/aqueduct/forest, หอคอย, อาคารต้นฉบับ, ถนนซ่อม และชั้นบัง 5 จุด
- กล้องเลื่อนด้วยการลาก/แตะบน iPad, ปุ่มข้ามเมืองตะวันตก–กลาง–ตะวันออก, ซูม 100–200%, ติดตามตัวละคร
- แสงกลางวัน–กลางคืนตามเวลาในชุดทดสอบ ปุ่มบังคับกลางวัน/กลางคืน และโคมไฟกับหน้าต่างจาก P0
- Rig 6 ชิ้นประกอบจริง 4 ชุด: ช่างตีเหล็ก, เสมียนสูงวัย, เด็กฝึกงานหญิง, เด็กส่งของ
- ท่ายืน/เดิน/ทำงานจาก Rig P1: ช่างตีเหล็กยกค้อน, เด็กฝึกงานช่วยงาน, เด็กส่งของ, ตัวละครเดินกลับที่พักตามตารางทดสอบ
- ผู้เล่นใช้สไปรต์เดิม แสดงแบบเดินอัตโนมัติ (ไม่มีปุ่มบังคับโจมตี/ต่อสู้)
- แตะตัวละครเพื่อดูชื่อและสถานะ เปลี่ยนความเร็วเวลา หยุด/เล่นต่อ
- ทุกไฟล์ภาพและสคริปต์อยู่ในโฟลเดอร์เดียวกันภายใต้ `phase5`, ไม่ต้องพึ่ง CDN หรือ API

## ขอบเขตสำคัญ

ชุดนี้เป็น **หน้า Preview พร้อมเล่นฉากเมือง** ไม่ใช่การแก้ซอร์สเกมจริง: ไม่มีไฟล์เกมหลัก v71 ล่าสุดอยู่ในชุดต้นทางและการดาวน์โหลด repository ตรงถูกจำกัด จึงยังไม่อาจเชื่อม NPC, collision, เซฟ, ระบบวันเวลา และ AI เข้ากับ `game.js` ของเกมหลักอย่างปลอดภัย การทำเช่นนั้นโดยไม่เห็นซอร์สจริงเสี่ยงทำเกมเดิมพัง

ความคมที่ 200% ถูกจำกัดตามรายละเอียดต้นฉบับ การเลื่อน parallax เป็นการเลื่อนแยกชั้นภายในขอบภาพ ไม่ใช่วงเมฆไม่มีที่สิ้นสุด การนำเข้า Phase 5 หลักและทดสอบ Safari บน iPad จริงยังต้องทำต่อ

## การตรวจที่ทำ

- ภาพทุกชิ้นที่โหลดในหน้า QA: ไม่มีภาพพลาด
- Rig `smith`, `teen`, `elder`, `child`: พร้อมแสดงครบ 4/4
- ไม่พบ page JavaScript errors
- ปุ่มซูม 150%, กลางคืน, เลือกติดตามช่างตีเหล็ก, เปลี่ยนความเร็ว x12 และการหยุดเวลาใช้งานได้
- ทดลอง viewport 1210×834 และ 834×1210 ใน Chromium ไม่ใช่ Safari จริง
- ตรวจไฟล์ภาพต้นทาง, ขนาด, SHA256 และ relative paths จาก manifest
