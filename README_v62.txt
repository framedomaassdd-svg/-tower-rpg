Tower RPG v62 — ซ่อมรอยต่อฉากและคุณภาพภาพ

ใช้กับ repository ที่มีเกม v60 หรือ v61 จากชุดนี้เท่านั้น
ชุดนี้รวมการจัดฉาก v61 และงานแก้ภาพ v62 แล้ว ไม่ต้องอัปชุด v54

วิธีอัปโหลดด้วย iPad
1. แตะ ZIP นี้ในแอปไฟล์เพื่อแตกไฟล์
2. เข้า repository เกมใน GitHub แล้วเลือก Add file > Upload files
3. เลือกไฟล์ทั้งหมดที่อยู่ภายในโฟลเดอร์ที่แตก (ไม่ใช่ตัว ZIP และไม่ใช่โฟลเดอร์)
   นำไปวางที่ตำแหน่งเดียวกับ index.html เดิม
   อัปโหลด README นี้ไปด้วยได้ ไม่มีผลต่อเกม
4. ไฟล์ที่มีชื่อเดิมให้แทนที่ จากนั้นกด Commit changes
5. รอ GitHub Pages อัปเดตแล้วเปิดเกมใหม่ หากภาพยังเป็นเดิมลองโหลดหน้าใหม่

สำคัญ: ต้องอัปโหลดไฟล์ภาพทุกไฟล์ในชุดพร้อมไฟล์โค้ดด้วย ไฟล์ PNG บางตัวเป็นไฟล์ใหม่
ZIP สำหรับดาวน์โหลดมีขนาดใหญ่เพราะบรรจุภาพคุณภาพสูง แต่เมื่อแตกแล้วแต่ละไฟล์ไม่เกิน 3 MB
ไม่ต้องลบไฟล์หรือภาพอื่นใน repository เดิม

สิ่งที่เปลี่ยน
- แก้ขอบทางเท้ากับลาน จุดสีฟ้าที่ขอบลาน และรอยต่อกำแพงประตูเมือง
- จัดตำแหน่งฉากหลังเพื่อลดภาพภูเขาที่ซ้ำเป็นเงากระจกหลังโรงตีเหล็ก
- ปรับประตูพร้อมซุ้มหินเป็นภาพชิ้นเดียว และปรับขนาด/ตำแหน่งธง
- ใช้ภาพหอคอยที่เจนปรับรายละเอียดจากต้นฉบับ โดยมีภาพก่อนปรับเก็บไว้เป็นสำรอง
- กู้ภาพที่ใช้ในเมืองและชานเมืองจาก PNG ต้นฉบับมาเป็น WebP แบบไม่สูญเสียรายละเอียด
- เก็บม้านั่งที่ระบบชีวิตใช้และเอารถเข็นที่ซ้อนเสาไฟออก
- ปรับตำแหน่งแสงโคมให้ตรงหลอด

ระบบจำลองชีวิต มินิเกม และข้อมูลเซฟใช้โค้ดเดิมของ v60
ตรวจไฟล์ ระบบชีวิต จุดเดิน รอยสีฟ้า และวาดภาพจากโค้ดเกม 14 จุดในเมือง
รวมกลางคืน ชานเมือง และสัดส่วนหน้าจอแนวนอน/Retina ในตัวจำลอง canvas
ยังไม่ได้ทดสอบ v62 บน iPad Safari หรือบนเว็บไซต์ที่เผยแพร่จริง
ภาพคุณภาพสูงทำให้ไฟล์ดาวน์โหลดและเวลาโหลดครั้งแรกอาจมากกว่า v60
